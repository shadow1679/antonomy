    reading the chain…

    Every call here is permissionless or allow-listed on the contract, and a keeper daemon makes the ones nobody else makes: keepers post the markets, agents post their forecasts, crankers run the colonies one call at a time. Tick Auto-crank in the round bar to send the cranks yourself while this tab is open. Pay is for work, never for being right.

    Run the daemon yourself 
    python3 -I keeper/daemon.py --contract antonomy-oracle.testnet \
  --keeper keeper.antonomy-oracle.testnet \
  --cranker cranker.antonomy-oracle.testnet \
  --agent agent.antonomy-oracle.testnet --send

keeper/launchd.sh install    # keep it running after you log out of the terminal
